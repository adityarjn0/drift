# Drift Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this
> plan in this session. Steps use checkboxes for tracking.

**Goal:** Deliver an interactive generative print studio with reproducible
artwork and high-resolution PNG export.

**Architecture:** Validated settings drive a deterministic geometry generator.
A canvas renderer paints that geometry at any size. The interface changes
settings and displays the latest composition, with URL state for reproducibility.

**Tech stack:** TypeScript, Canvas 2D, Vite, Vitest, Playwright, and axe-core.

**Spec:** `docs/superpowers/specs/2026-09-30-drift-design.md`

## Global constraints

- Seeds are whole numbers from 1 to 999999.
- Density is 20–100; flow is 0–100.
- Logical geometry is 720 × 960; PNG export is 2400 × 3200.
- No runtime dependencies or remote assets.
- Follow the Google TypeScript style guide and run all configured checks.

## Review focus

- Malformed URL values restore safe defaults rather than crash.
- Invalid seed edits keep the current artwork and expose an accessible error.
- Rapid edits export the latest composition rather than stale geometry.
- The entire interface fits a 320px viewport and remains keyboard usable.
- Preview resize and PNG export preserve the same composition.
